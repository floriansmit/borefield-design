Location → geological column

On GitHub Pages, address search and REGIS import run directly in your browser using PDOK and TNO public services. GitHub Pages does not expose the GET endpoints shown below; these document the optional server handler in worker/api.mjs. The same handler is reused as browser-api.mjs, keeping validation and layer conversion consistent.

Address search

GET /api/geocode?q=Utrecht&

Pass a Dutch address or place in q (3–180 characters, URL encoded). Returns up to six PDOK Locatieserver matches with a label, identifier, WGS84 POINT and feature type. Select the intended result; the API never assumes the first match is the right address.

REGIS profile

GET /api/regis?lat=52.0907&lon=5.1214&depth=320

WGS84 latitude and longitude; requested depth in metres below ground (30–600). Optional surface gives the site elevation in metres NAP. Without it, the REGIS model surface mv is used and labelled accordingly.

Returns ordered layers with code, top/base below ground, original topNAP/baseNAP where available, a generic preset, and gap flags. Also returns requested and sampled RD coordinates, surface reference, source/model version, retrieval date and warnings.

Data: TNO / BRO REGIS II v02r2s3, OPeNDAP dataset REGIS.nc, 100 m cells. WGS84→RD uses the standard polynomial approximation (metre-scale accuracy). Close to a cell boundary this may select a neighbouring cell; verify the returned cell centre against your GIS for precision work.

Unit suffix z → sand; k → clay; Drenthe Gieten → till; Woudenberg v → peat; selected chalk units → chalk. Complex and other units remain unknown. These are generic lithological interpretations requiring review. REGIS hydraulic conductivity is not thermal conductivity. No hydraulic value is converted into a thermal property.

Regional model layers may not resolve local heterogeneity. Overlaps are clipped with warnings; gaps and below-model intervals remain unclassified. Thermal defaults are applied by the client catalogue, not claimed to be REGIS measurements.

Errors: 400 invalid inputs, 404 no data/outside grid, 502 upstream/schema/timeout error. No synthetic profile is substituted for a failed request.

Calculation engines

Thermal calculations run in the browser worker; there is no hosted calculation API. For reuse, application model code exposes Borefield.validate, Borefield.evaluate and Borefield.optimize. The Python kernel.py wrapper can also run under ordinary Python with pygfunction==2.3.1 installed.
